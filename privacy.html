台9線 App 隱私權政策

我們非常重視您的隱私。本政策說明您在使用「台9線即時路況資訊」（以下稱「本 App」）時， 我們可能蒐集、使用、儲存與分享哪些資料，以及您擁有哪些權利。

一、我們蒐集哪些資料

1) 帳號與登入資料（Firebase Authentication）

當您註冊或登入本 App（含匿名/訪客、Email、或第三方登入方式）時， 我們會透過 Firebase Authentication 建立與管理您的帳號識別資訊，例如： 使用者識別碼（UID）、登入狀態資訊，以及您提供的帳號(Google帳號, Apple帳號)。

2) 使用者產生內容（UGC）

當您在本 App 發佈或提交內容時，我們會蒐集並儲存您提供的資訊，例如： 路況回報（如事故/施工/落石/警察等類型）、地圖標點、文章/留言/圖片（若功能開放）、 以及您輸入的文字內容與相關欄位（如事件描述）。

3) 位置資料（定位權限）

若您允許定位權限，本 App 可能會取得您的位置資料用於以下目的： 顯示您附近路況、建立/上傳回報事件的位置、在地圖上標示事件、以及提升內容的地理正確性。

重要說明：當您進行「回報/標點/上傳」等功能時，事件座標與相關內容可能會被上傳至雲端資料庫， 以提供其他使用者查看（或供您跨裝置使用）。

4) 相機、照片與媒體（若您使用上傳照片/截圖等功能）

若您使用拍照、上傳照片或選取相簿圖片作為回報內容，本 App 會請求相機或照片權限。 您選取或拍攝的影像僅會在您操作上傳/發佈時被處理與儲存（例如上傳至雲端 Storage）， 不會在未經您操作的情況下自動上傳。

5) 推播通知資料（Firebase Cloud Messaging）

若您允許通知權限，本 App 可能使用 Firebase Cloud Messaging（FCM）向您發送通知。 系統可能會產生推播所需的裝置權杖（Token），用於將通知傳送至您的裝置。

6) 可能的廣告資料（若本 App 含廣告）

若本 App 版本包含廣告（例如插頁式廣告），第三方廣告服務可能會蒐集裝置識別資訊 （例如 Advertising Identifier / IDFA 或類似識別碼）、大略位置、裝置與使用資訊，用於投放與衡量廣告成效。 實際蒐集項目會依您裝置系統設定與您是否授權追蹤而有所不同。

二、我們如何使用資料

  • 提供核心功能：顯示路況、地圖標點、內容發佈與回報上傳。
  • 帳號與資料同步：讓您可跨裝置登入並保留您的發佈/回報/貢獻紀錄。
  • 提升服務品質與安全：防止濫用、垃圾內容、異常操作，並維護系統安全。
  • 通知您重要資訊：例如您關注的路況、系統公告（需您允許通知）。
  • （若含廣告）提供與衡量廣告投放。

三、資料儲存位置與第三方服務

本 App 使用 Firebase 相關服務（由 Google 提供）以支援登入、資料庫、檔案儲存、雲端函式與推播。 因此，您的資料可能會被儲存在雲端伺服器上，並由 Firebase 依其安全機制進行保護與處理。

  • Authentication：用於登入與帳號管理
  • Database / Firestore：用於儲存回報、標點、文章/留言等資料（依功能）
  • Storage：用於儲存您上傳的圖片或媒體（依功能）
  • Cloud Functions：用於伺服器端處理（例如清除帳號資料、資料整理等）
  • Cloud Messaging：用於推播通知（依您授權）

四、資料分享對象

我們不會販售您的個人資料。僅在下列情況可能分享或揭露：

  • 為提供服務而必須：例如透過 Firebase 代管與傳輸資料。
  • 您主動公開的內容：例如您發佈的回報/標點/貼文可能會被其他使用者看見（依你 App 的設計）。
  • 遵循法律或主管機關要求：在合法程序下配合提供必要資訊。
  • （若含廣告）廣告服務供應商：用於投放與衡量廣告。

五、資料保留與刪除

我們會在提供服務所需期間內保留您的資料。您可在本 App 內提出帳號刪除或資料刪除（若功能提供）， 系統將依流程刪除或匿名化與您帳號相關的資料；但部分資料可能因法規或系統備援需求而在合理期間內留存。

六、權限說明

  • 定位：用於附近路況顯示、事件定位、回報上傳與地理匹配。
  • 相機/照片：用於拍攝或選取圖片進行回報或發文（依功能）。
  • 通知：用於推播重要路況或系統訊息（依您授權）。

您可以隨時於 iOS 系統設定中關閉上述權限，但部分功能可能因此無法正常使用。

七、資料安全

我們採取合理的技術與管理措施保護資料安全（例如存取控管與傳輸加密）。 但網路傳輸並非百分之百安全，我們無法保證絕對無風險。

八、兒童隱私

本 App 非以兒童為主要對象。若您為未成年人，請在法定監護人同意與指導下使用本 App。

九、政策更新

我們可能因功能調整或法規需求更新本政策。更新後會於本頁公布最新版本與更新日期。
